# coordinator-stats

Статистика использования **профилей** в текущем проекте + предложение новых профилей на непокрытые паттерны. Часть роли координатора как точки входа (диспетчера).

## Порядок

1. **Slug + память:** `basename "$(git rev-parse --show-toplevel 2>/dev/null || pwd)"` → `coordinator/<slug>/`.

2. **Бэкфилл (если ещё не делали).** Нет `profile-usage.jsonl` или в нём нет пометки бэкфилла → просканить `./swarm-report/*.md`, смапить имя файла на профиль эвристикой (`refactoring-*`→Рефакторинг, `hazard-hunt*`/`*audit*`→Поиск бага, `research-*`→Исследование, `*e2e*`→E2E тестирование, `*feature*`/`topup*`/`*grant*`→Бизнес-фича и т.п.). Дописать записи (`"backfill":true`, дата из имени файла).

3. **Роллап.** Пересобрать `profile-stats.md` из `profile-usage.jsonl`:
   - Таблица `профиль → счётчик` (по убыванию).
   - Топ-3 самых частых, мёртвые/редкие профили.
   - Непокрытые паттерны (`matched:false`) сгруппированные по смыслу.

4. **Показать юзеру** дайджест статистики.

5. **Предложение новых профилей.** Непокрытый паттерн повторился ≥3× → предложить новый профиль через `AskUserQuestion` (название + суть). По «ок»:
   - Сгенерить черновик `~/.claude/profiles/<name>.md` по формату существующих профилей.
   - Добавить строку роутинга в `CLAUDE.md` (ключевые слова автодетекта + строка в таблице профилей).
   Без «ок» — только зафиксировать предложение в `profile-stats.md`, файлы не трогать.

## Инварианты

- Статистика **по-проектно** (не глобально).
- Создание профиля / правка CLAUDE.md — только после явного «ок» юзера.
- Read-only по коду проекта; пишет в свою память + (по «ок») в `~/.claude/profiles` и `CLAUDE.md`.

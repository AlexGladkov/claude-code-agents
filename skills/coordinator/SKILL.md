# coordinator

Один **пульс** координатора над текущим проектом. Смотритель read-only: собирает недоделки, ловит дрейф от генеральной линии, предлагает юзеру меню следующих шагов. Ничего не меняет в проекте — пишет только в свою память.

## Как запустить

Делегируй пульс агенту `coordinator` через Task tool (агент лежит в `agents/control/coordinator.md`):

```
Task(subagent_type: "coordinator", prompt: "<исходный запрос юзера> — выполни один read-only пульс над текущим проектом по своей методологии")
```

Агент сам:
1. Определит slug проекта (`basename` корня git-репо).
2. Прочитает свою память `coordinator/<slug>/` (или уйдёт в Bootstrap-интервью, если проект новый).
3. Отсканит сигналы (git log/status, ветки, TODO/FIXME, PR/issues, e2e-сценарии, свежие отчёты) — read-only.
4. Сравнит с генеральной линией, соберёт дайджест.
5. Тихий пульс (без меню) если ничего не поменялось, иначе — 2-4 кандидата действий через `AskUserQuestion`.
6. Запишет результат в память.

## Инварианты

- **Read-only** по проекту. Мутации — только в `coordinator/<slug>/`.
- Решает юзер. Агент вправе возразить при дрейфе в костыль/техдолг.
- Русский язык.

## Рекуррентный пульс

Чтобы гонять пульс по расписанию (напр. каждые 10 мин) — оберни в `/loop`:

```
/loop 10m /coordinator
```
